# 艺旅清风智慧监督系统 — 高保真交互原型实现计划

## 概述

基于 Next.js 16 + React 19 + TypeScript 5 + shadcn/ui + Tailwind CSS 4 技术栈，构建「纪检廉政管理系统」高保真交互原型。核心覆盖业务功能模块（10分）和低代码开发模块（10分），共 27 个页面，政务蓝主色调，PC 端为主兼顾大屏展示，全部采用脱敏模拟数据，全页面可点击跳转、流程可完整走通。

## 技术方案

| 维度 | 选择 | 理由 |
|------|------|------|
| 框架 | Next.js 16 (App Router) | 沙箱环境最佳支持，HMR 热更新 |
| UI 组件 | shadcn/ui (Radix UI) | 预装组件库，政务风格易定制 |
| 样式 | Tailwind CSS 4 + CSS 变量 | 主题化方便，响应式适配 |
| 图表 | Recharts | 轻量 React 图表库，满足统计图表需求 |
| 流程图 | ReactFlow | 流程设计器核心依赖 |
| 拖拽 | @dnd-kit/core | 表单设计器拖拽能力 |
| 图标 | Lucide React | shadcn/ui 默认图标库 |
| 数据 | 纯前端 Mock 数据 | 原型阶段无需后端 |

## 功能模块

### 一、业务功能模块（演示分值 10 分）

#### 1. 廉政概览首页（Dashboard）
- 顶部统计卡片：人员总数、违纪人数、待处理案件、预警数量
- 左侧："四种形态"柱状图、"四风"问题饼图、人员职级分布
- 右侧：近期动态列表、预警信息列表、处分到期提醒
- 每个统计卡片可点击钻取到详情

#### 2. 档案管理模块（2.5 分）
- **档案列表页**：表格展示，含筛选（职级/部门/政治面貌）、搜索、分页；操作按钮：录入/编辑/分类填报/批量导入/批量下载/信息对比/档案退回/定时回收/意见管理
- **档案录入/编辑页**：Tab 分类填报（基本信息/职务信息/廉政情况/考核信息/附件），完整表单字段
- **档案信息对比页**：双版本选择器 + 字段级差异对比（红色标注变更项）+ 版本历史时间线
- **档案意见管理页**：意见申请弹窗（选择审批人/填写申请内容）、审批列表（待审批/已通过/已驳回）、意见回复弹窗
- **定时回收页**：回收站列表 + 还原/彻底删除 + 定时回收设置弹窗

#### 3. AI 廉政分析模块（2.5 分）
- **AI 对话页**：对话窗口（打字机效果）、快捷问题入口、对话历史侧栏
- **分析结果展示**：图表 + 文字说明混合展示
- **招采预警列表**：预警列表 + 预警详情弹窗 + 数据来源标注
- **分析报告生成**：报告预览 + 导出按钮

#### 4. 全流程案件管理模块（2.5 分）
- **案件流程总览页**：流程进度条（8 阶段）+ 案件基本信息卡片
- **8 个阶段子页面**：信访举报 → 线索处置 → 谈话函询 → 初步核实 → 立案审查 → 案件审理 → 复议复查 → 以案促改
- 每个阶段页面含：表单录入/记录列表/审批操作/附件上传
- 流程节点可点击跳转，展示完整案件流转

#### 5. 台账管理模块（2.5 分）
- **信访举报台账**：列表 + 多条件筛选（时间/类型/状态）+ 导出
- **线索处置台账**：列表 + 进展跟踪 + 导出
- **处置情况统计**：柱状图/饼图 + 时间范围筛选 + 导出
- **党纪处分统计**：分类统计表 + 图表 + 导出

### 二、低代码开发模块（演示分值 10 分）

#### 1. 表单设计器（2 分）
- 三栏布局：左侧组件库（8 种组件）、中间设计画布（拖拽）、右侧属性配置面板
- 组件：文本、下拉框、日期、图片、用户、部门、数字、附件
- 支持单列/双列/三列布局切换、实时预览、保存

#### 2. 列表设计器（2 分）
- 布局切换：列表形式/目录形式/卡片形式
- 列配置弹窗、功能按钮配置（新增/修改/删除/导入/导出）
- 查询条件配置、实时预览

#### 3. 流程设计器（2 分）
- ReactFlow 画布 + 左侧节点库（开始/审批/会签/条件/并行/结束）
- 条件分支配置、并行分支配置
- 手写签名组件（Canvas 实现）

#### 4. 权限控制（2 分）
- 功能菜单权限：菜单树 + 勾选授权
- 数据权限：本人/本部门/全部/自定义
- 字段权限 + 操作权限配置

#### 5. 版本管理（2 分）
- 版本列表（开发版/测试版/正式版）
- 创建版本弹窗、历史版本查看
- 版本回退、版本差异对比

### 三、系统支撑模块

- 组织权限管理、日志审计（三员管理）、消息管理、预警管理

## 实施步骤

### 阶段一：原型设计

1. **加载 design-canvas 技能，完成原型设计**
   - 按 design-canvas 技能规范，基于功能清单生成完整原型 HTML 页面
   - 涉及：design-canvas 技能加载 + 原型 HTML 生成

### 阶段二：代码开发

2. **初始化 Next.js 项目并配置主题**
   - 用 `coze init` 创建 nextjs 模板，运行 theme.sh 配置政务蓝主题
   - 涉及：`.coze`、`globals.css`、`layout.tsx`

3. **搭建全局布局与 Mock 数据**
   - 创建侧边栏导航 + 顶部 Header 的主布局，准备所有 Mock 数据文件
   - 涉及：`src/components/layout/`、`src/mock/`

4. **实现业务功能模块（10 分）**
   - 廉政概览首页、档案管理（列表/录入/对比/意见/回收）、AI 分析（对话/预警/报告）、案件管理（流程总览 + 8 阶段）、台账管理（4 类台账）
   - 涉及：`src/app/(dashboard)/`、`src/app/archive/`、`src/app/ai/`、`src/app/case/`、`src/app/ledger/`

5. **实现低代码开发模块（10 分）**
   - 表单设计器、列表设计器、流程设计器、权限控制、版本管理
   - 涉及：`src/app/lowcode/`、ReactFlow、@dnd-kit

6. **实现系统支撑模块**
   - 组织权限、日志审计、消息管理、预警管理页面
   - 涉及：`src/app/system/`

7. **全流程联调与验证**
   - 确保所有页面可点击跳转、流程完整走通、弹窗/筛选/导出/分支逻辑全部可用
   - 涉及：`test_run` 工具验证
